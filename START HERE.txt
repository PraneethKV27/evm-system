SecEVM — How to start from your Desktop folder
==============================================

DO NOT double-click index.html — the backend will NOT work that way.

TO START THE APP:
  1. Double-click  "START SecEVM.bat"  or  "SecEVM.bat"
  2. Wait for the black window to say "SecEVM is ready"
  3. Your browser opens at http://localhost:3000

BACKEND (fingerprint server):
  http://127.0.0.1:5002/status

REQUIREMENTS:
  - Node.js 18+ installed from https://nodejs.org/
  - First run installs dependencies automatically

IF BACKEND SHOWS "DISCONNECTED":
  - Make sure SecEVM.bat is still running (don't close the window)
  - Close the window and double-click SecEVM.bat again
